# Fonts

- `fredoka.woff2`: Fredoka (variable weight 300 to 700), used for headings.
- `nunito.woff2`: Nunito (variable weight 200 to 1000), used for body text.

Both are Latin subsets from Google Fonts and are licensed under the SIL Open
Font License 1.1. The licence allows bundling them with the game, but the
licence text and each font's copyright notice must ship alongside them. Add
`OFL-Fredoka.txt` and `OFL-Nunito.txt` here before any public release.
